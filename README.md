# ConstrainCert for Windows

Portable-приложение для Windows, которое разрешает сертификаты Минцифры только для выбранных доменов и их поддоменов. Версия v1 рассчитана на Chrome и Edge.

## Что делает приложение

1. Создаёт на компьютере локальный anchor с критичным `Name Constraints`.
2. Выпускает cross-сертификат root Минцифры с тем же публичным ключом.
3. Помещает anchor в `CurrentUser\Root`, а cross - только в `CurrentUser\CA`.
4. Разрешает сертификаты Минцифры только для выбранных DNS-доменов. IP, email и URI заблокированы.

Приватный ключ anchor существует только в памяти во время создания цепочки. В файлы, release и хранилища сертификатов он не записывается.

## Первый запуск

1. Скачайте `constraincert-win-x64.zip` из Releases и распакуйте архив.
2. Запустите `ConstrainCert.App.exe`.
3. Нажмите «Набор Точка» или добавьте свои конкретные домены.
4. Нажмите «Применить» и полностью перезапустите Chrome или Edge.
5. Нажмите «Проверить» и убедитесь, что приложение пишет об активной защите.

Набор «Точка» содержит `tochka.com`, включая все его поддомены.

## Важно

- ConstrainCert не работает, если Windows уже доверяет оригинальному неограниченному root Минцифры. Приложение покажет это и не станет автоматически удалять чужой сертификат.
- Нельзя добавлять `.ru`, `.su`, `.рф`, URL и IP-адреса.
- Firefox, Android, MSI и подпись кода пока не поддерживаются.
- «Удалить всё» удаляет только сертификаты, SHA-256 которых сохранены самим приложением в `%LocalAppData%\ConstrainCert\state.json`.

## Ручная проверка

На отдельном Windows-профиле после применения:

1. Откройте публичный домен из выбранного набора, когда он действительно использует сертификат Минцифры.
2. Откройте сайт Минцифры вне списка, например `abr.ru`. TLS-проверка должна завершиться ошибкой ограничения сертификата.
3. Нажмите «Удалить всё», перезапустите браузер и повторите первую проверку. Сайт Точки больше не должен проходить только за счёт ConstrainCert.

## Разработка

Нужен .NET SDK 8:

```powershell
dotnet test ConstrainCert.sln --configuration Release
dotnet publish src/ConstrainCert.App/ConstrainCert.App.csproj --configuration Release --output publish
```

GitHub Actions собирает self-contained single-file `win-x64` архив, запускает тесты и отказывается публиковать файлы, похожие на закрытые ключи.
